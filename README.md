# Portfólio | Thayssa Braga

Meu portfólio pessoal, feito com **HTML, CSS e JavaScript** puros, sem frameworks.

🔗 **Acesse:** https://thayssadev.github.io

## O que tem no site

- Apresentação, sobre mim e habilidades
- Projetos com links para o site publicado e o código
- Layout responsivo com menu para celular
- Animação das seções ao rolar a página
- Ícones de contato (e-mail, LinkedIn e GitHub)

## Tecnologias

- HTML5 semântico
- CSS3 (Flexbox, Grid, variáveis e media queries)
- JavaScript (DOM, IntersectionObserver e Clipboard API)

## Como rodar localmente

Clone o repositório e abra o `index.html` no navegador:

```bash
git clone https://github.com/ThayssaDev/thayssadev.github.io.git
```
